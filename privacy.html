공부판 개인정보처리방침

시행일: 2026-09-19

수집하는 정보

앱은 사용자가 직접 입력한 할 일, 복습 항목, 상태 체크인, 그리고 공부 모드가 켜져 있는 동안 앞에 떠 있던 앱의 패키지 이름과 사용 시간을 기기 안에 저장합니다.

구글 계정과 드라이브

사용자가 드라이브 연결을 켜면, 앱은 사용자의 구글 드라이브 안 지정한 폴더(기본 이름 "학습시스템")에 log.json 파일을 쓰고, 같은 폴더의 message.json 파일을 읽습니다. 그 밖의 드라이브 파일은 읽거나 수정하지 않습니다. 구글 사용자 데이터는 이 기능을 위해서만 쓰며, 누구에게도 전송·판매·공유하지 않습니다.

공부판이 구글 API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

제3자 제공

개발자가 운영하는 서버는 없습니다. 데이터는 사용자의 기기와 사용자 본인의 구글 드라이브에만 저장됩니다.

삭제

앱을 삭제하면 기기 안의 데이터가 지워집니다. 드라이브에 저장된 파일은 사용자가 드라이브에서 직접 지울 수 있고, 구글 계정 설정의 "타사 앱 및 서비스"에서 접근 권한을 언제든 철회할 수 있습니다.
